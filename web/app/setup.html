Set up this machine

Choose a role first. A machine can be both: a library server that also reads its own volumes, or a library elsewhere plus a processor here.

1. Library server Library folder, address, the admin account, remote access, OCR on this machine. 2. Processor Connect this machine to a library as an OCR processor: address, login, connection test, name, sessions. 3. OCR install Detect the GPU, install the matching backend pack and the models, check everything. 4. Start with the machine A user service (systemd, launchd or the Startup folder) for the server or the processor.

Every step has a command-line twin: mokuro-bunko setup, processor setup, install-ocr, processor service --install.
